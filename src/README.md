# Python Package Overview

This folder contains the Python package for the Distributed Ticket Booking System.

## Included modules

- `dist_ticket_booking/core/` — data models and shared state
- `dist_ticket_booking/coordination/` — locks and distributed coordination
- `dist_ticket_booking/scheduler/` — order and fairness handling
- `dist_ticket_booking/simulation/` — scenario execution
- `dist_ticket_booking/monitoring/` — logging and system tracking

## Milestone 1 note

The structure is intentionally scaffolded, not fully implemented. The goal is to establish a clear Python-first distributed-systems foundation.
